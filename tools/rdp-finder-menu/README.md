# Finder 远程文件菜单（assist.80 预览）

Windows 中复制文件后，在 Mac 目标 Finder 文件夹的**空白处右键**，选择带 Calabi 图标的「粘贴远程文件」。这版入口不使用 ⌘V。

安装阶段针对当前登录用户自动注册并请求启用菜单（pluginkit -a / -e use）。没有登录用户时延后到首次使用，宿主每构建首次使用可再尝试一次。同一构建之后用户手动停用，继续尊重该选择。自动启用在后台完成。如果 Finder 中缺少菜单，可主动点击菜单栏的「Calabi 远程桌面 → 远程文件菜单设置…」打开扩展设置。普通 macOS 目标目录的访问限制仍适用。实际系统启用与菜单显示须真机确认。

菜单范围是当前用户主目录及 `/Volumes` 下的文件夹空白处；搜索结果、其他用户目录、文件条目的右键菜单不在本轮范围。仅剪贴板带当前远程文件标记时提供菜单，最终由接收端核验当前会话、清单和剪贴板序号。传输仍使用现有 Calabi 自有通道，不经过普通文件传送 tab，也不依赖普通接收开关。

接收端固定目标目录描述符，逐个文件流式写入该目录的隐藏 `.calabi-receive-*.partial`，成功后以不覆盖方式原子改名；重名追加 ` (1)` 等编号。取消、断线或读取失败清除当前未完成文件，已经完成的文件保留。只由 Calabi 显示进度与取消，不发起 Finder 复制操作。传输后无需第二次粘贴。复制完成后可再次执行菜单，重新下载；同一清单不接受两个同时进行的接收。

单独构建 Finder 扩展：在源码根目录运行 `bash tools/rdp-finder-menu/build.sh /tmp/CalabiRemoteFiles.app --universal`。完整客户端还需要桌面应用和 RDP 助手。

本机 Windows 不具备 macOS SDK，未验证 Mac 原生编译及真实 Finder 菜单。Mac 构建脚本将执行真实接收函数的 fixture，包括目录改名后仍写入固定目录、跨块内容、重名保留、取消和失败清理、空文件。通过 fixture 仍不替代真实菜单、权限、UI 和网络验收。

真机检查：

1. 安装新 pkg 前退出旧 Calabi 和远程窗口；安装后新开远程登录，勾选允许复制文件，确认正常自动启用且不弹设置窗口。
2. Windows 复制一个小文件；Mac 在 Downloads 的目标文件夹空白处右键执行菜单。检查名称、内容及只有 Calabi 进度。
3. 多文件包含中文名、空文件与已有同名文件；核对内容、逐个进度、完成数量和重名保留。
4. 大文件中途取消；检查关闭按钮有效、未完成文件清理、无 Finder 错误对话框；重新复制后再试。
5. 接收期间结束远程会话，检查清理；在两个 Finder 目录分别执行，确认落盘位置正确。

日志：`log stream --style compact --level info --predicate 'eventMessage CONTAINS "FINDER_MENU_"'`。不记录完整目标路径、令牌或文件内容。
