# 组网文件传送与远程访问

[English](mesh-file-and-remote-access.md) · [Calabi 中文 README](../README.zh-CN.md)

本文适用于 Calabi 2.7.0。先把两台设备连到同一个组网，并确认组网访问规则和目标设备的入站设置允许连接。使用自建服务器时，请使用支持文件传送的协调器。服务器和组网配置见[自建指南](self-hosting.zh-CN.md)。

| 要做什么 | 从哪里开始 | 适用范围 |
| --- | --- | --- |
| 把本地文件发送给另一台组网设备 | 「组网 → 文件传送」 | Windows、macOS、Android，以及运行 Calabi 文件服务的 Linux。支持自建和 calabi.net 组网。 |
| 在 Windows 远程桌面会话中复制文件 | 「组网 → 设备 → 更多 → 远程登录」 | Windows 或 macOS 桌面客户端连接由 calabi.net 识别为同一用户所有的 Windows 设备。 |
| 打开 Linux 终端或通过 SFTP 管理文件 | 「组网 → 设备 → 更多 → 远程登录」 | Windows 或 macOS 桌面客户端连接组网内的 Linux 设备。支持自建和 calabi.net 组网。 |

## 组网设备之间传送文件

1. 在接收端打开「允许接收文件请求」。文件接收默认关闭。Windows 和 macOS 上进入「组网 → 组网设置 → 本机接收」，也可以从「文件传送」页的接收状态直接跳到开关。开关即时生效。Android 上直接在「文件传送」页开启。
2. 在发送端打开「组网 → 文件传送 → 发送文件」，选择已在线并开启接收的设备，选好文件后发送。也可从设备的「更多」菜单发起。Android 还可以从系统分享面板选择 Calabi。
3. 在接收端接受请求。双方可在「文件传送」页查看进度，接收方可将传完的文件另存到需要的位置。

Linux 使用 Calabi 文件服务及其文件管理页面。运行 `calabi mesh files service status` 查看服务状态，运行 `calabi mesh files service web-url` 生成一次性浏览器配对链接，在文件管理页面开启接收。使用托管文件服务的 Linux 接收端也可以主动开启自动保存。

## 在 Windows 远程桌面中双向复制文件

1. 两端都安装 Calabi。被控端需要使用可作为远程桌面主机的 Windows 版本，启用 Windows 远程桌面，并允许所用的 Windows 账号远程登录。组网访问规则须放行 RDP 端口，默认是 TCP `3389`。
2. 在 Windows 或 macOS 控制端打开 Calabi，进入「组网 → 设备」，在目标 Windows 设备的「更多」菜单选择「远程登录」。填写账号、密码和端口，勾选「允许复制文件（最多 100 MiB）」后连接。
3. 在源端的资源管理器或 Finder 中复制文件。在目标端打开要保存的文件夹，在空白处右键选择「粘贴远程文件」。Windows 11 上可在「显示更多选项」中查找。macOS 上如果 Calabi 提示启用远程文件菜单，请在系统设置中启用对应的 Finder 扩展。

本地到远端 Windows、远端 Windows 到本地都可以复制。每批最多 32 个普通文件，总计最多 100 MiB。复制使用当前远程会话，普通「允许接收文件请求」开关关闭时也能使用。Windows 被控端的后台文件代理和粘贴助手须保持运行。

Calabi 内置 RDP 登录要求协调器确认两端设备属于同一个 calabi.net 用户。通过自建邀请加入的设备没有这项用户归属信息。自建组网中，如果网络策略和 Windows 设置允许，可以用独立的 RDP 客户端连接目标设备的组网地址。

## 连接 Linux SSH 终端并使用 SFTP

1. 在目标 Linux 上加入组网并运行 SSH 服务。组网策略和主机防火墙须允许所用的 SSH 端口，默认是 TCP `22`。要使用文件面板，SSH 服务还须启用 SFTP 子系统，远端账号须具备相应的文件或目录权限。
2. 在 Windows 或 macOS 桌面客户端进入「组网 → 设备 → 更多 → 远程登录」，选择目标 Linux 设备。Calabi 使用系统 OpenSSH。Windows 如果缺少 OpenSSH 客户端，请安装相应的系统可选功能。填写 Linux 账号和端口，可输入密码，也可留空使用已保存的密码或 OpenSSH 密钥。首次连接时核对服务器主机指纹。
3. 连接后将鼠标移到远程窗口右侧边缘，展开会话控件并打开「文件」。可以浏览远端目录、上传本地文件，或选择远端文件下载和删除，支持多选。SFTP 使用与终端相同的 SSH 端口和账号，按该账号的文件权限操作。

## 最近登录与保存密码

RDP 或 SSH 登录成功后，设备会出现在「组网 → 远程」。选择记录可重连，弹出登录框时再点「连接」。默认关闭密码记忆。主动勾选后，密码保存在当前电脑的 Windows 凭据管理器或 macOS 钥匙串。要删除已保存的密码，请在登录框中选择「清除凭证」。
